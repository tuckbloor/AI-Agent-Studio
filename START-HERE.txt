AGENT STUDIO v2.2 — COMPLETE INSTALL (NO PATCHES)
================================================

1. Close the old AI App Server window (port 8501).
2. Extract this ZIP to E:\ so you have this folder:
      E:\Agent-Studio-AI-App-Server-v2.2-COMPLETE
3. Open that folder and double-click INSTALL AND RUN.bat.
4. Only when the installer says INSTALLED AND VERIFIED, visit:
      Home:   http://127.0.0.1:8501/
      Admin:  http://127.0.0.1:8501/admin
      Editor: http://127.0.0.1:8501/admin/studio
5. Sign in through the existing admin login before using the editor.

No existing AI App Server engine, login, configuration or database is replaced.
The installer backs up the previous Agent Studio extension and checks that its
routes have actually been registered before reporting a successful install.
An occupied port does NOT mean the installation failed; close the old instance.

TRY THE BENSONS FOR BEDS RESEARCH
================================
1. Open the Agent Studio editor through /admin.
2. Describe: "Find prices for super king beds at Bensons for Beds.
   Follow relevant product links and show the product name, price and URL."
3. Select your Ollama model. Click Design my agent.
4. Confirm the proposed workflow contains Live Web Search.
5. Click Use this design, then Run saved job.
6. In the run timeline, look for "Retailer identified" and
   "Opening relevant page". It will try the official super-king
   category and site navigation before Bing's public results.
7. It may report no VERIFIED product prices if the shop refuses
   automated access, uses JavaScript-only prices, or the size
   cannot be confirmed. It should still show relevant official links.

WHAT IT CAN AND CANNOT DO
========================
- Does NOT require a paid search API key for the built-in mode.
- Opens up to 12 public HTTPS pages, following at most 2 link levels.
- Checks robots.txt, rejects private/internal network destinations,
  and does not bypass retailer access restrictions.
- Confirms product and (where requested) size evidence before listing prices.
- Does NOT guarantee live retailer access or a final checkout total.
- Browser/Internet access from our testing environment is restricted;
  real retailer access must be tested on your Windows computer.
